# StudyFlow - 智能学习任务规划器

> 数据结构与算法课程大作业 · 2026 秋季学期
>
> 作者：熊鑫

## 项目背景与目标

**面向谁？** 大学在校学生，面临多门课程、多个作业和考试的学习任务管理需求。

**解决什么问题？** 传统待办清单工具缺乏智能调度能力，无法根据截止日期、优先级和任务依赖关系自动生成最优学习计划。StudyFlow 利用数据结构与算法，将学习任务按紧急度自动排序，并考虑前置依赖关系，生成每日可执行的学习计划。

**已完成功能：**
- ✅ 课程管理（增删改查）
- ✅ 学习任务管理（标题、课程、截止日期、预计时间、优先级、描述、标签）
- ✅ 任务前置依赖管理（基于有向图）
- ✅ 智能每日计划生成（基于最小堆优先队列 + 依赖图）
- ✅ 前缀搜索（基于 Trie）
- ✅ 学习统计仪表盘
- ✅ 图形界面（Tkinter）

## 课程知识与核心设计

### 1. 最小堆（MinHeap）— 任务调度

**文件:** `src/studyflow/heap.py`

自定义实现二叉最小堆，用于按紧急度排序待执行任务。

- **时间复杂度:** 插入 O(log n)，弹出 O(log n)，建堆 O(n)，堆排序 O(n log n)
- **空间复杂度:** O(n)
- **关键操作:** `push`, `pop`, `peek`, `heapify`, `to_sorted_list`
- **设计理由:** 相比每次全排序 O(n log n)，使用堆只需 O(log n) 即可获取最紧急任务，适合频繁的动态插入和弹出场景
- **紧急度公式:** `urgency = -(100/(days+1) - priority*10)`，使 min-heap 弹出最紧急任务

### 2. 有向图（DependencyGraph）— 依赖管理

**文件:** `src/studyflow/graph.py`

用邻接表存储任务依赖关系，支持环路检测和拓扑排序。

- **环路检测:** DFS 三色标记法，O(V+E)，防止依赖死锁
- **拓扑排序:** Kahn 算法（BFS 入度法），O(V+E)，给出建议学习顺序
- **可执行任务:** `get_ready_tasks(completed)` 返回所有前置已完成的任务
- **设计理由:** 邻接表适合稀疏图（任务依赖通常较少），相比邻接矩阵更节省空间

### 3. Trie（前缀树）— 快速搜索

**文件:** `src/studyflow/trie.py`

支持中文字符的前缀树，用于按任务标题、课程名称和标签快速搜索。

- **插入:** O(m)，m 为字符串长度
- **搜索:** O(m + k)，k 为匹配结果数
- **设计理由:** 前缀搜索比线性扫描 O(n·m) 更高效，尤其适合大量任务时的即时搜索

### 4. 哈希表 — 高效查找

Python `dict` 用于任务和课程的 O(1) 平均查找，与 Trie 互补使用。

### 方案对比

| 场景 | 选择方案 | 替代方案 | 选择理由 |
|------|---------|---------|---------|
| 任务调度 | 最小堆 | 每次全排序 | 动态场景下 O(log n) vs O(n log n) |
| 依赖管理 | 邻接表 | 邻接矩阵 | 稀疏图节省空间 |
| 搜索 | Trie | 线性扫描 | 前缀搜索性能更好 |
| 存储 | JSON | SQLite | 轻量，便于版本管理和人工查看 |

## 安装与运行

### 环境要求

- Python 3.10+
- 无需额外第三方依赖（仅使用标准库 tkinter、json、dataclasses 等）

### 安装步骤

```bash
# 1. 克隆仓库
git clone <your-repo-url>
cd StudyFlow

# 2. (可选) 复制演示数据
copy data\demo_data.json data\studyflow.json

# 3. 运行程序
python src/main.py
```

### 在 PyCharm 中运行

1. 用 PyCharm 打开 `StudyFlow` 文件夹
2. 右键 `src/main.py` → Run 'main'
3. 或配置 Run Configuration：Script path = `src/main.py`，Working directory = 项目根目录

### 运行测试

```bash
cd StudyFlow
python tests/test_heap.py
python tests/test_graph.py
python tests/test_trie.py
python tests/test_models.py
python tests/test_planner.py
```

## 功能展示

### 仪表盘

- 顶部显示任务总数、已完成、已逾期、完成率四个统计卡片
- 输入可用时间后点击"生成计划"，自动按紧急度排列今日任务
- 被前置依赖阻塞的任务单独列出

### 任务管理

- 所有任务以表格形式展示，支持按标题、课程、截止日期、优先级排序
- 搜索框使用 Trie 实现前缀匹配
- 双击任务可编辑，支持设置前置依赖

### 课程管理

- 管理课程信息（名称、教师、学分）
- 每个课程关联的任务数自动统计

*(运行程序后可见完整界面)*

### 边界与异常处理

- 空标题任务 — 验证失败提示
- 负数预计时间 — 验证失败提示
- 优先级超出 1-5 — 验证失败提示
- 空堆操作 — 返回 None
- 循环依赖 — 拒绝添加，返回 False
- 空搜索 — 返回空列表
- 已过期截止日期 — 允许保存但显示警告

## 局限与改进

### 已知局限

- 单日计划不支持跨天调度（当前只生成当天计划）
- 无提醒/通知功能
- 不支持重复任务
- GUI 仅支持桌面（Tkinter），无 Web 或移动端
- 数据存储在本地 JSON，不支持多设备同步
